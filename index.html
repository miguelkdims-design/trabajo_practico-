Examen Práctico 2: Git y GitHub

Proyecto colaborativo para la gestión de versiones y control de cambios sobre algoritmos de PSeInt.

Integrantes del Equipo

  • Miguel Espinoza B — Configuración del repositorio y algoritmo principal
  • [Nombre del Segundo Integrante] — Validaciones, mejoras y documentación
  • [Nombre del Tercer Integrante] — Pruebas y control de commits

Instrucciones de Uso

  1. Clonar el repositorio público desde GitHub usando git clone.
  2. Abrir el archivo .psc en PSeInt.
  3. Ejecutar el algoritmo e ingresar los datos solicitados en pantalla.
  4. Registrar cada modificación mediante git add, git commit y git push.
Nota: Cada integrante debe registrar sus aportes mediante commits identificables en el historial del repositorio.
